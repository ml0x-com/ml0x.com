Why DeepSeek-V3 MLA changes KV cache math

Standard multi-head attention with 128 attention heads and 128 head_dim across 61 layers would store 2 × 61 × 128 × 128 × 2 = 4.00 MB per token in BF16. DeepSeek-V3's Multi-head Latent Attention (MLA) projects keys and values into a single shared low-rank latent vector of dimension kv_lora_rank = 512 plus a decoupled RoPE key vector of qk_rope_head_dim = 64. Per token, MLA stores only 61 × (512 + 64) × 2 = 70,272 bytes (~68.6 KiB) in BF16 — a 56.9× reduction over naive MHA.

Frequently asked questions

How much VRAM does DeepSeek-V3 671B need in native FP8?

DeepSeek-V3 is trained natively in FP8 (E4M3). Its 671B weights take ~684 GB of VRAM. Adding MLA KV cache and CUDA graph overhead brings a typical serving deployment to ~740-820 GB, which fits cleanly on a single 8x H200 (1,128 GB) or 8x B200 (1,536 GB) node, or two 8x H100 nodes.

Can DeepSeek-V3 671B run on a single 8x H100 80GB node?

Not in native FP8 (684 GB weights exceed 640 GB total VRAM on 8x H100). However, in INT4 / AWQ / Q4_K_M (~403 GB weights), DeepSeek-V3 fits comfortably on one 8x H100 80GB node with ~200 GB left for MLA KV cache and concurrent requests.

Why is DeepSeek-V3 decode speed faster than a 671B dense model?

DeepSeek-V3 is a Mixture-of-Experts (MoE) model that activates only 37B parameters per token out of 671B total. Single-stream memory bandwidth only reads the 37B active weights per forward pass (~37 GB in FP8), giving decode speeds closer to a 32B-40B dense model.

How much VRAM does DeepSeek-V3's MLA KV cache use at 128k context?

At 128,000 tokens in BF16, one request uses 61 layers x (512 + 64) x 2 bytes x 128,000 = 8.99 GB (8.38 GiB). In FP8 KV cache, that drops to 4.50 GB per 128k stream.

Can I run DeepSeek-V3 locally on a Mac Studio M3 Ultra 512GB?

Yes. With GGUF Q4_K_M (~403 GB) or Q2_K_XL (~228 GB), DeepSeek-V3 fits in a 512 GB M3 Ultra's unified memory (up to ~448 GB wired GPU allocation). At 800 GB/s bandwidth reading 37B active params in Q4 (~22 GB), expect ~18-28 tok/s single-stream.
