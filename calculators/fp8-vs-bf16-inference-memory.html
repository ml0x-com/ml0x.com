Frequently asked questions

Does FP8 inference hurt LLM accuracy compared to BF16?

Across MMLU, GSM8K, and HumanEval benchmarks, dynamic per-tensor/blockwise FP8 (E4M3) preserves >99.5% of BF16 accuracy on 8B–671B models.

Which GPUs support native hardware FP8?

NVIDIA Hopper (H100, H200), Blackwell (B200, RTX 5090), and Ada Lovelace (L40S, RTX 4090) all include native FP8 Tensor Cores. Older Ampere A100 GPUs lack native FP8 compute and must dequantize.

Can I use FP8 weights with BF16 KV cache?

Yes — vLLM and SGLang allow mixing FP8 weights with either BF16 or FP8 KV cache, though FP8 KV cache doubles your max batch size on long contexts.
