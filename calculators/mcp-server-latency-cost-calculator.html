Frequently asked questions

How many tokens does each MCP tool add to context?

A typical MCP tool JSON schema with parameter descriptions uses 350 to 600 tokens. Forty active tools inject roughly 19K tokens on every turn.

Do idle MCP servers still cost money?

Yes. Even if the model never calls a server during a session, its tool definitions are still sent in the prompt prefix unless the server is disabled for that project.

How can I reduce MCP latency in Claude Code?

Disable unused servers in project .mcp.json files, prefer local stdio servers over remote HTTP hops, and batch read calls before editing.
