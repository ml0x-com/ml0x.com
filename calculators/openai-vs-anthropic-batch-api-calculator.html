Frequently asked questions

How much do OpenAI and Anthropic Batch APIs save?

Both OpenAI's Batch API and Anthropic's Message Batches API discount standard input and output token rates by exactly 50% in exchange for a 24-hour asynchronous SLA (most batches finish in 1-4 hours).

Can you combine Anthropic prompt caching with the Message Batches API?

Yes. Anthropic allows prompt cache reads (0.10x input price) inside Message Batches, stacking with the 50% batch discount so shared system prompts and few-shot examples cost 95% less than uncached synchronous calls.

What workloads are best suited for Batch APIs?

Offline LLM-as-a-judge evaluations, document classification, structured data extraction, synthetic dataset generation, nightly catalog enrichment, and embedding-adjacent summarization.

What are the batch size limits on OpenAI vs Anthropic?

Anthropic Message Batches accept up to 100,000 requests or 256 MB per batch. OpenAI Batch API accepts up to 50,000 requests or 200 MB JSONL per batch file, with separate higher enqueued token limits than synchronous RPM/TPM pools.

How do GPT-4.1-mini and Claude Haiku 3.5 compare in Batch mode?

In Batch mode, GPT-4.1-mini ($0.20 in / $0.80 out per 1M) is roughly half the price of Claude Haiku 3.5 ($0.40 in / $2.00 out), making it a strong default for high-volume classification, while Haiku 3.5 and Sonnet 4 shine when stacking heavy prompt caching.
