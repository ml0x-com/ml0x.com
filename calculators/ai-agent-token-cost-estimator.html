Frequently asked questions

Why do AI agent costs grow quadratically with step count?

Because transformers are stateless, step N re-sends the system prompt plus all N-1 previous messages and tool outputs. Doubling agent steps from 15 to 30 nearly quadruples total input tokens.

What is the fastest way to cut AI agent token bills by 50%+?

Combine prompt caching (80–90% cache hit rate on static prefixes) with aggressive tool-output compaction (truncating verbose logs/HTML before appending to history).

How do hard gateway budget caps protect production agents?

A gateway or hook-level budget cap tracks cumulative dollar spend per run ID and terminates stuck retry loops automatically before they exhaust your monthly API quota.
