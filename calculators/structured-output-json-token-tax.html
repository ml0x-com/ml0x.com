Frequently asked questions

Why do structured JSON outputs cost more tokens than plain text?

JSON repeats key names, quotes, colons, and braces in every object, expanding completion tokens by 20% to 45% while also injecting the JSON schema into every input prompt.

Does prompt caching cover JSON tool schemas?

Yes. Placing your tool definitions and JSON schemas in a static prefix lets Anthropic cache them at 0.10x read cost across consecutive calls.

How can I reduce validation retries on structured outputs?

Use constrained decoding (strict mode), keep nesting depth at 1 or 2 levels, and provide one concise few-shot example in the cached prefix.
