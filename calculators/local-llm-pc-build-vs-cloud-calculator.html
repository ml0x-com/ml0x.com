Frequently asked questions

How long does it take for a local RTX 5090 LLM rig to pay for itself?

At 6 active hours/day (144 hrs/mo) compared against a $1.10/hr cloud GPU, a $4,200 RTX 5090 workstation costs ~$17/mo in electricity and pays for itself in roughly 29-30 months. Against a $350/mo API habit, payback drops to ~13 months.

Is Mac Studio M4 Ultra or 2x RTX 4090/5090 better for local LLMs?

NVIDIA RTX 4090/5090 rigs have 2x-3x faster prompt processing (prefill) and higher tokens/sec for 8B-70B models, while Mac Studio M4 Ultra (192GB-512GB unified memory at 800 GB/s) runs massive 235B-671B MoE models at ~180W that simply cannot fit in desktop GPU VRAM.

How much electricity does a local AI PC use per month?

A single RTX 5090 workstation drawing ~650W under load for 6 hours/day, 24 days/month uses ~94 kWh/month — roughly $17/mo at $0.18/kWh (or ~$33/mo in high-tariff regions like California or Europe).

Does a local LLM rig have resale value after 3 years?

Yes. High-VRAM NVIDIA GPUs and Apple Silicon Macs historically retain 35%-55% of their purchase price after 3 years, which effectively cuts your real net depreciation payback window nearly in half.

When is cloud or API still better than buying local hardware?

If you only run heavy inference 1-2 hours/day, need frontier closed models (Claude Opus 4 / Sonnet 4), or burst to 8x H100s for occasional fine-tuning, cloud pay-as-you-go beats local CapEx easily.
