Frequently asked questions

Do cached prompt tokens count toward Anthropic ITPM rate limits?

On Claude 4 models, cache read tokens do not count toward your Input Tokens Per Minute (ITPM) limit. Raising cache hits from 50% to 85% more than triples safe concurrency.

Why do I hit 429 errors on Anthropic Tier 1 so quickly?

Tier 1 allows only 30K uncached ITPM. A single uncached 45K context turn can exceed Tier 1 immediately, so serious Claude Code usage requires at least Tier 2.

How do Claude Max 5-hour rolling windows compare to API tiers?

Claude Max $100 and $200 meter usage over rolling 5-hour windows instead of per-minute token buckets, making them great for steady solo work while direct API suits high-concurrency CI bursts.
