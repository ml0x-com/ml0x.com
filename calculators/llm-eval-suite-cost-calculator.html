How much does Batch API save on LLM eval suites?

Both Anthropic and OpenAI offer a flat 50% discount on asynchronous Batch API jobs, which can stack with prompt caching on shared grading rubrics.

Should I use Opus 4 or Sonnet 4 as my LLM judge?

Use Sonnet 4 or Haiku 3.5 for binary rubric checks and formatting assertions; reserve Opus 4 for a smaller golden sample of nuanced reasoning checks.

How do teams prevent CI eval costs from exploding on active repos?

Split suites into a 50-case smoke set that runs synchronously on every PR and a full regression suite that runs nightly via the 50% Batch API.
