Frequently asked questions

How long should a CLAUDE.md file be?

Aim for 80 to 250 lines (roughly 1.1K to 3.5K tokens). Put module-specific instructions in nested subdirectory CLAUDE.md files so they only load when needed.

Why do MCP tool schemas consume so much context?

Each MCP tool definition includes a JSON schema and description averaging 400 to 600 tokens. Connecting 60 tools injects nearly 30K tokens before you type a single prompt.

Does prompt caching eliminate CLAUDE.md token cost?

Prompt caching cuts static prefix reads by 90%, but large prefixes still reduce usable reasoning headroom and trigger earlier auto-compaction.
