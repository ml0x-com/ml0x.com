Frequently asked questions

Can Llama 4 Scout run on a single H100 80GB GPU?

Yes in INT4 (~61 GB weights), leaving ~15 GB for KV cache and activations. In FP8 (~114 GB weights), Scout requires either 1x H200 (141 GB) or 2x H100 (160 GB).

Why do MoE models like Llama 4 Maverick still need VRAM for all 400B parameters?

Even though only 17B parameters activate per token, the router can dispatch tokens to any expert at any layer, so all 128 experts must stay resident in HBM unless you accept severe PCIe offload latency.

How much does FP8 KV cache save on long Llama 4 contexts?

Switching KV cache from BF16 to FP8 cuts KV cache memory exactly in half, doubling your supported context length or concurrent batch size on the same GPU pool.
