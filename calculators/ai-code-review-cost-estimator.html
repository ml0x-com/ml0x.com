Frequently asked questions

How much does AI code review cost per pull request?

For a 220-line PR with 24K repo rules context on Claude Sonnet 4, two review passes typically cost between $0.05 and $0.12 per PR.

How do I stop lockfiles from spiking PR review costs?

Filter out package-lock.json, yarn.lock, pnpm-lock.yaml, and minified build outputs in your git diff command before sending diffs to the model.

Should we use Sonnet 4 or Opus 4 for automated PR reviews?

Use Sonnet 4 as the default for all PRs and escalate to Opus 4 only when a PR touches auth, billing, migrations, or core security modules.
